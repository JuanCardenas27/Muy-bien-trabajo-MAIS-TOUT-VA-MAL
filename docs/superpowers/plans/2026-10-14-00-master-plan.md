# Frances Classroom — Plan maestro de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Lee `AGENTS.md` antes de tomar una tarea.

**Goal:** Construir la app personal de estudio de francés que sincroniza Google Classroom a diario, genera tarjetas, fichas y audios pre-generados y evalúa la pronunciación con Azure.

**Architecture:** Un pipeline Python (`frances`) idempotente por etapas con SQLite como store de trabajo, persistido como volcado SQL más archivos content-addressed en un bucket privado de Cloudflare R2 (`frances-data`). Los workflows de producción corren en GitHub Actions del repo público, sin escribir datos en él. Una SPA React estática servida por GitHub Pages descarga el bundle FRB1 desde un Worker de Cloudflare y lo descifra en el navegador. La clonación de voces es un proyecto aislado (`clone/`) que corre por lotes en el PC del usuario.

**Tech Stack:** Python 3.11–3.13, uv, Typer, pydantic v2, httpx, google-auth, boto3, pypdfium2, Tesseract, spaCy, lingua, edge-tts, cryptography · Node 22, Vite, React, TypeScript, ts-fsrs, idb, pdfjs-dist, Azure Speech SDK JS, vite-plugin-pwa · Chatterbox Multilingual / XTTS v2, faster-whisper · GitHub Actions + Pages · Cloudflare R2 + Workers (wrangler).

## Global Constraints

- Python `requires-python = ">=3.11,<3.14"` en `frances`; CI con 3.11 y 3.12.
- Node 22 LTS, TypeScript `strict: true`, ESM. `.npmrc` con `save-exact=true`; se commitean `package-lock.json` y `uv.lock`.
- Licencias: código importado en `src/frances` y `web/` solo MIT/BSD/Apache-2.0/ISC/MPL-2.0. Herramientas GPL (espeak-ng) solo como binario en subprocess. ffmpeg, igual: solo como binario.
- Tests sin red: `pytest --disable-socket` (pytest-socket) y en vitest `fetch` siempre mockeado. Los tests que necesitan red o modelos pesados se marcan `@pytest.mark.heavy` y no corren en CI.
- El repo público solo contiene datos sintéticos (`tests/fixtures/**`, generados por `tests/fixtures/make_fixtures.py`). Nunca un nombre, archivo o texto real del Classroom. Los datos reales viven solo en el bucket R2 y en la copia local `data/` (en `.gitignore`).
- Secretos solo por variables de entorno. Toda salida de log pasa por `frances.log.redact()`. Nunca se imprime una clave, un token, la passphrase ni contenido del curso.
- Timestamps: siempre se guardan con `frances.timeutil.norm_ts()` → `YYYY-MM-DDTHH:MM:SS.ffffffZ` (UTC, 6 decimales). Se muestran en `America/Bogota`.
- Normalización de texto solo con `frances.textnorm` (`norm_key`, `tts_norm`, `display_clean`).
- IDs exactamente según «Reglas de IDs» más abajo.
- Archivos ≤ 400 líneas, una responsabilidad. Cada tarea escribe su SQL solo en módulos que posee (`repo.py`, o funciones privadas `_q_*` en su módulo si el `repo.py` es de otra tarea); el DDL vive solo en `src/frances/db/migrations/`.
- UI en español; todo texto en francés va dentro de un elemento con `lang="fr"`.
- Exit codes de la CLI: `0` ok · `1` error inesperado · `2` parcial (estado guardado, hay ítems con error) · `3` autenticación (no se escribió nada) · `4` configuración inválida.
- Azure Speech: locale `fr-FR`, región desde config (por defecto `eastus`).
- Audio: MP3 mono, 24 kHz, 48 kbps, loudness integrada −16 LUFS.
- Bundle publicado ≤ 900 MB; adjunto descargado ≤ 50 MB.

## Review Focus

1. Timestamps de Classroom con decimales variables (`…:23Z` frente a `…:23.045123456Z`) comparados como texto → actualizaciones perdidas. Se espera normalizar al ingerir. Test: SYN-04 `test_watermark_variable_fraction_digits`.
2. La profesora reemplaza el PDF en Drive sin editar la publicación → hay que re-descargarlo por `version`. Test: FET-03 `test_refetch_when_drive_version_changes`.
3. La misma palabra con apóstrofo tipográfico, NFD o comillas francesas desde dos materiales («l’école», `l'école`) → una sola tarjeta y el progreso se conserva. Test: FND-02 `test_card_id_typography_invariant`, CRD-05 `test_merge_keeps_card_and_adds_source`.
4. Descarga restringida, export > 10 MB o archivo > 50 MB → la publicación sigue visible con enlace y la CLI sale con 2, no con 1. Tests: FET-03 `test_forbidden_download_is_partial`, `test_export_too_large_falls_back_to_text`.
5. Passphrase incorrecta, micrófono denegado o Safari iOS sin permisos → mensaje claro en español, sin pantalla rota. Tests: WEB-04 `wrong passphrase shows error and keeps input`, PRN-02 `mic denied moves to error state with message`.

## Layout del bucket R2 `frances-data` (y `DataPaths`)

El bucket es privado y es la única copia persistente de los datos. Bajo `data/` replica el directorio de datos (`DataPaths(root)`, `--data DIR`); `frances r2 pull|push` (OPS-03) lo sincroniza. `frances.toml` y `voices.yaml` no viven en el bucket: salen de `deploy/` del repo y se copian al directorio de datos antes de cada corrida.

| Atributo de `DataPaths(root)` | Ruta | En R2 (`data/…`) |
|---|---|---|
| `config` | `frances.toml` | no (viene de `deploy/`) |
| `voices_yaml` | `voices.yaml` | no (viene de `deploy/`) |
| `voice_refs` | `voices/refs/` | sí |
| `state_sql` | `state/state.sql` | sí (con `If-Match`) |
| `state_db` | `.cache/state.db` | no |
| `blob_path(sha)` | `blobs/<sha[:2]>/<sha>` | sí |
| `extraction_path(sha, ver)` | `extractions/<sha>.<ver>.json` | sí |
| `audio_path(key)` | `audio/<key>.mp3` | sí |
| `cache` | `.cache/` | no |

Fuera de `data/`: `site/bundle.json`, `site/d/<id>.bin` y `site/builds/<build_id>.txt` (lo único que expone el Worker), `snapshots/state-<YYYY-MM-DD>.sql` (60 días por regla de ciclo de vida), `locks/writer.json` (lease) y `data/notes/` (resultados de las tareas LIVE).

## Reglas de IDs (`frances.models.ids`)

```python
ITEM_PREFIX = {"coursework": "cw_", "material": "mt_", "announcement": "an_"}
def item_id(kind: ItemKind, classroom_id: str) -> str            # ITEM_PREFIX[kind] + classroom_id
def attachment_id(item_id: str, kind: AttachmentKind, external_id: str) -> str
    # "at_" + sha256(f"{item_id}\x1f{kind}\x1f{external_id}").hexdigest()[:16]
def card_id(front_fr: str, kind: CardKind) -> str
    # "c_" + sha256(norm_key(front_fr) + "\x1f" + kind).hexdigest()[:16]
def content_hash(*parts: str) -> str                               # sha256("\x1f".join(parts)).hexdigest()
```

`frances.textnorm`:

```python
def display_clean(s: str) -> str  # NFC, espacios repetidos → uno, recorta extremos; conserva ’ « » y espacios finos
def tts_norm(s: str) -> str       # display_clean + ’→' + espacios finos/no separables → espacio normal; conserva mayúsculas y puntuación
def norm_key(s: str) -> str       # tts_norm + casefold + quita « » " y puntuación de los extremos
```

### FRB1 (BND-01 Python, WEB-02 TypeScript; los dos validan `tests/fixtures/frb1_vectors.json`)

```
master    = PBKDF2-HMAC-SHA256(NFC(passphrase) UTF-8, salt, iterations, 32 bytes)
enc_key   = HKDF-SHA256(master, salt=b"", info=b"FRB1 enc",   32 bytes)   → AES-256-GCM
nonce_key = HKDF-SHA256(master, salt=b"", info=b"FRB1 nonce", 32 bytes)
nonce     = HMAC-SHA256(nonce_key, SHA256(plaintext))[:12]      # determinista: el mismo contenido da el mismo archivo
blob      = b"FRB1" || nonce || AESGCM(enc_key).encrypt(nonce, plaintext, aad=b"FRB1")   # tag de 16 B al final
file id   = SHA256(blob).hexdigest()[:32]   → publicado como d/<id>.bin
check     = b64url(blob de b"FRB1-OK")       # va en bundle.json para detectar passphrase incorrecta
índice    = gzip(JSON UTF-8 de ContentIndex) cifrado como cualquier blob
```
