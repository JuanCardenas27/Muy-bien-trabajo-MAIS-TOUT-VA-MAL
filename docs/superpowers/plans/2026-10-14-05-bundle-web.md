# Bundle cifrado y app web -- Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Lee `AGENTS.md` antes de tomar una tarea.

**Goal:** Empaquetar el estado del pipeline en un bundle FRB1 cifrado (índice + archivos `d/*.bin`) y construir la SPA que lo descifra en el navegador: desbloqueo, Hoy, Classroom, fichas, repaso FSRS, tarjetas, audio, ajustes, PWA offline y e2e sobre un demo sintético.

**Architecture:** `frances.bundle` (Python) lee el `Store`, construye un `ContentIndex`, cifra cada archivo con FRB1 en `out_dir/d/<id>.bin` y escribe `bundle.json`. La SPA (Vite + React + TS estricto) deriva la clave con WebCrypto, la guarda como `CryptoKey` no extraíble en IndexedDB, descarga y descifra el índice y los archivos bajo demanda, y guarda el progreso (SRS, ajustes) solo en IndexedDB.

**Tech Stack:** Python 3.11–3.13, `cryptography`, Typer, pydantic v2 · Node 22, Vite, React, React Router, TypeScript strict, `idb`, `ts-fsrs`, `pdfjs-dist`, `vite-plugin-pwa`, vitest + @testing-library/react + @testing-library/user-event + `fake-indexeddb`, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-14-frances-classroom-design.md` (§6.6 Bundle, §6.7 App, D2, D9, D10)

Plan maestro: docs/superpowers/plans/2026-10-14-00-master-plan.md (Global Constraints y contratos aplican a todas las tareas)

## Restricciones del subsistema

- UI en español. Toda cadena visible sale de `web/src/i18n/es.ts` (`t(key)`), definido completo en WEB-01.
- Todo texto en francés (front_fr, example_fr, frases clave, ejemplos de gramática) va dentro de un elemento con `lang="fr"`.
- WCAG 2.1 AA: navegable con teclado, foco visible, ARIA en controles, contraste ≥ 4.5:1 verificado por test (WEB-01), los puntajes y estados nunca dependen solo del color.
- Nada de síntesis de audio en runtime: el navegador solo reproduce MP3 del bundle; si falta un clip muestra «Audio pendiente (…)».
- Sin analytics, fuentes remotas, CDNs ni requests a terceros. Los únicos orígenes son el propio sitio (`BASE_URL`) y Azure Speech (P06).
- Tests web: `fetch` siempre mockeado; los tests de cripto llevan `// @vitest-environment node` (WebCrypto completo de Node 22); IndexedDB con `import "fake-indexeddb/auto"`. Los tests de UI usan `TestContentProvider` (WEB-03) en lugar de cripto real.
- Tests Python sin red (`--disable-socket`); lo que llama a `espeak-ng`/`ffmpeg` va con `@pytest.mark.heavy`.
- Comando web por archivo: `npm --prefix web test -- <ruta relativa a web/>` (el script `test` de FND-01 es `vitest run`).
